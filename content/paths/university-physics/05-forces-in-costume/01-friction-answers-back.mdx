<Step>

## Name it

Along the slope gravity pulls with $mg\sin\theta$. Into the slope the block presses with
$mg\cos\theta$, so the grip limit is $\mu_s\,mg\cos\theta$. The block holds while

$$mg\sin\theta \;\le\; \mu_s\,mg\cos\theta \quad\Longleftrightarrow\quad \tan\theta \;\le\; \mu_s$$

<Recall id="up-ch05-recall-static" concept="static-friction">
  <div slot="front">A crate is pushed with 8 N and does not move. The floor could grip with up to 30 N. What is the friction force?</div>

  8 N. Static friction is whatever stops the slipping, up to 30 N. It reaches $\mu_s N$ only at
  the instant before the crate goes.
</Recall>

</Step>

<Recall id="up-ch05-recall-kinetic" concept="kinetic-friction">
  <div slot="front">A block needs a 31° ramp to start sliding. Once it slides, you lower the ramp to 27°. What happens?</div>

  It keeps sliding and keeps speeding up. Sliding friction, $\mu_k N$, is smaller than the static
  limit, so the block glides steadily only where $\tan\theta = \mu_k$, and stops below that.
</Recall>

## What to carry forward

- **Static friction is an answer, not a formula.** It matches whatever it must, up to $\mu_s N$.
- **Slipping is a race between two forces that both scale with m**, so the block slips where $\tan\theta = \mu_s$, for any mass.
- **Sliding is a different model**: $\mu_k N$, smaller, so a moving block is easier to keep moving.
