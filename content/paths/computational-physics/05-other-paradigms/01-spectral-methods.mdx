You already know how to differentiate from samples: look left, look right, divide.
That stencil is **local**. Each derivative uses two neighbours and ignores the rest.

Here is a different bet. Treat the samples as the values of one trigonometric
polynomial — a sum of sines and cosines that fits every point at once — and
differentiate *that*. Every sample talks to every other sample. Differentiation
becomes multiplication by $ik$ in frequency space.

## Add modes until it snaps

You are about to keep Fourier modes one at a time and watch $S_K$ approach
$\exp(\sin x)$. First, commit to the shape of the error.

For a smooth periodic function the error does not pick an order. It falls **faster
than every power of** $K$, then sits on the roundoff floor. That is spectral
accuracy.

The mechanism is one line. If

$$
u(x) = \sum_k \hat{u}_k e^{ikx}
$$

then

$$
u'(x) = \sum_k ik\,\hat{u}_k e^{ikx}
$$

A derivative is a multiplier. Sample, DFT, multiply by $ik$, inverse DFT. No
stencil. The Nyquist mode of an even grid is a cosine whose sine-derivative
vanishes at every node, so that slot is set to zero:

```ts
const spec = dft(samples);
const kappa = waveNumbers(n);          // 0, 1, …, n/2−1, 0, 1−n/2, …, −1
for (let k = 0; k < n; k++) {
  const wr = -kappa[k] * spec.im[k];   // multiply by iκ
  const wi =  kappa[k] * spec.re[k];
  spec.re[k] = wr;
  spec.im[k] = wi;
}
return idft(spec).re;
```

## Now break it with one jump

The catch is the word *smooth*. Fourier modes are global and $2\pi$-periodic. A
single jump is a singularity on the real axis, and every mode feels it.

Now toggle **one jump** in the lab above. The same modes that reconstructed
$e^{\sin x}$ to machine precision now ring at the discontinuity. The spectrum bars
no longer die. The error plot's cliff becomes a shallow slope, and a muted wall
sits near $\pi/2$ because a continuous $S_K$ cannot match a jump in max-norm.

The overshoot itself is a theorem, not a bug. For a jump of height $a$, every
truncated Fourier series overshoots by

$$
\left(\frac{1}{\pi}\mathrm{Si}(\pi) - \tfrac{1}{2}\right) a \approx 0.0895\, a
$$

about nine percent, forever. Extra modes move the first peak closer to the jump.
They do not lower it.

<Recall id="spec-accuracy-card" concept="spectral-methods">
  <div slot="front">What happens to Fourier spectral accuracy when the function has a single jump?</div>

The rate collapses from exponential to first order, and the partial sums ring at
the discontinuity — Gibbs overshoot of about 9% of the jump, which does not die
with $K$.

Spectral accuracy needs smoothness *and* periodicity. A jump is a singularity on
the real axis; every mode feels it. Away from the jump the truncated series
converges like $1/K$, the same algebraic rate a forward difference already had.

</Recall>

<Tier level="advanced" title="non-periodic intervals: Chebyshev, not Fourier">

Fourier needs the function to be periodic *and* smooth. A perfectly smooth $u$ on
$[a,b]$ is not smooth when you wrap it: $u(a)$ and $u(b)$ generally disagree, and
that wrap is a jump. Gibbs eats the whole interval.

The polynomial analogue on $[-1,1]$ is a **Chebyshev** basis. Nodes cluster at the
endpoints,

$$
x_j = \cos(\pi j / N), \qquad j = 0,\ldots,N
$$

which is what stops the Runge phenomenon that equispaced polynomial interpolation
walks into. Differentiation is a dense $(N+1)\times(N+1)$ matrix — still a global
coupling, still exponential accuracy for analytic $u$, still destroyed by a jump.

The clustering is not a quirk. It is the image of equispaced Fourier nodes under
$x = \cos\theta$. Chebyshev *is* Fourier, after a cosine map. That is why the
same spectral-accuracy theorem applies, and why the same Gibbs wall appears the
moment $u$ fails to be smooth.

</Tier>

## What to carry forward

A local stencil buys a power of $h$. A global basis buys a cliff — or a wall.

The question that decides which you wanted: **if you double the modes, does the
error fall off a cliff or hit a wall?** Smooth and periodic, cliff. One jump,
wall, and first order from there on.
